# Tools

One folder per job. Python scripts put `tools/` on `sys.path` and import shared code from
`common/`; machine paths come from `common/paths.py` (each overridable by an environment variable).
Offline tools never touch the game; everything that drives the game is in `../cp2077_tools/mods/let_there_be_flight/` (cp2077_tools) and runs inside
`../cp2077_tools/game.py run`.

| Folder | What | Inputs, outputs |
|---|---|---|
| `common/` | `navmap.py` (the one navmap.bin reader), `paths.py`, `toolpath.py` (sibling folders on sys.path) | |
| `navplan/` | `navplan.cpp` (the planner offline, CMake target `navplan`), `follow.cpp` (the follower flown offline, `NAVPLAN_FOLLOW`), `bench.py` (benchmark routes, compare builds or parameters; also flies each line with the follower), `tune.py` (Optuna search), `measure.py` (shared by both), `ahead_sweep.py` (plan-ahead horizon and margin), `dips.py`, `plot.py`, `city.py`, `navviz.py` (planner's view over a recorded run), `routes.json`, `vehicles.json` | navmap.bin, routes; CSV, PNG, video |
| `navmap_bake/` | the nav map bake: `sectors`, `geometry_cache`, `presets`, `proxies`, `glb`, `rasterize`, `preview`, `spans`, `navmap`, `doorways`, `gates`; steps in its README | game archives; navmap.bin, `src/navigation/gates.tsv` |
| `world/` | city collision: `blockers.py` (hidden colliders), `proxy_colliders.py` (+ `physx_cook.py`), `collision_at.py` (what collision is in a box, down to the actor), `collider_cases.json` (known hidden and real colliders), `opened_patches.py` (space a bake change opened: hollow building or open air), `proxy_collider_force.json` (buildings given collision by hand) | sectors; `src/navigation/blockers.txt`, collider entities |
| `pads/` | landing pads: `pads.py`, `pad_*.py`, `flat_spots.py`, overrides and sector placement (`pad_sector.py`) | sectors, navmap.bin; `src/navigation/helipads.tsv`, pad entities, our sector |
| `../cp2077_tools/mods/let_there_be_flight/` (moved 2026-10-31) | `ltbf_bridge.reds` (LtbfBridge test helpers), `debug_draw/ltbf_draw.reds` (needs debug_draw), `lib.py`, `fly_route.py` (one recorded flight; `--bump` knocks it), `axis_sweep.py` (every flight control held in turn, recorded with stems), `sweep_follower.py` (follower gains over repeated knock tests), `free_roam.py`, `validate_bake.py`, `check_navmap.py`, `check_collider.py` (casts the collider cases' rays in game), `ray_probe.py` (segments through every raycast query), `helipad_toast.py` (the landing pad toast, recorded), `camera_flight_on.py` (flight on with the car parked, the TPP camera's height above the car sampled); `fly_route.py --ahead h,m|off` sets plan ahead, `check_patches.py` (puts the car beside opened patches for screenshots), `hangar_map.py` (the Badlands hangar's pin before and after the quest offer, its hatch, its box on the world map) | the running game; videos, telemetry |
| `acoustics/` | `flyby.py` (a recorded flight heard with echoes and reverb from the nav map), `probe.py` (rays through the nav map), `render.py` (the echo pairs and reverb), `acoustics.cpp` (the plugin's acoustics code offline, CMake target `acoustics`), `compare_features.py` (its features against flyby.py's), `compare_render.py` (its render against flyby.py's, per octave), `compare_live.py` (the in-game log of live collider against nav map distances), `stems_video.py` (a run's video with the plugin's FMOD stems as its audio tracks, `--extra` for a synth render), `engine_synth.cpp` (the engine synth over a run's thruster parameters, CMake target `engine_synth`), `engine_fit.py` (the synth against the FMOD event on the same run, per control held), `engine_variants.py` (a run's video with the synth's switches each way as tracks); `docs/design/engine-synth.md`; `docs/design/acoustics.md` | navmap.bin, Autopilot telemetry, `tools/acoustics/assets`; WAV, PNG, MP4 |
| `telemetry/` | `autopilot.py` (the Autopilot's per-frame CSV), `aerobatics.py` (`[AutopilotA]` log lines), `surge.py` (how much a flight held the surge, run against run), `fit_surge.py` (the car's surge share and drag from full-surge frames) | telemetry; summaries, plots |
| `physx/` | `pxscene_vtable.py` (PxScene's vtable slots in the game's PhysX3_x64.dll: raycast, sweep, overlap) | the game's PhysX DLL |
| `packaging/` | `pack_archive.py` (run by the build), `icons/` (map pin and AUTOPILOT logo), `physx_cook/` (the C++ PhysX cooker) | archive source; the .archive |
| `maintenance/` | `nexus_comments.py`, `minidump_addrs.py` | |
